Data Preparation and Cleaning

Project Overview

This project demonstrates the preparation and cleaning of a public Titanic dataset for data-science work.

The main objective is to identify and handle missing values, manage data types, remove duplicate records, and create a cleaned dataset that can be used for further analysis or machine-learning tasks.

Dataset

Dataset used: Titanic Dataset

The dataset is publicly available and contains information about passengers, including:

- Passenger class
- Sex
- Age
- Fare
- Embarked port
- Survival status
- Other passenger-related information

Data Preparation Steps

The following steps were performed:

1. Loaded the public Titanic dataset using Pandas.
2. Checked the dataset shape and missing values.
3. Handled missing values:
   - Missing "Age" values were replaced using the median.
   - Missing "Embarked" values were replaced using the mode.
   - Missing "Fare" values were replaced using the median.
4. Converted required columns to appropriate data types:
   - "Survived" → integer
   - "Pclass" → integer
5. Removed duplicate rows.
6. Checked the dataset again for remaining missing values.
7. Displayed the first five rows of the cleaned dataset.
8. Saved the cleaned data as "cleaned_titanic.csv".

Assumptions

- Median imputation was used for missing numerical values because it is less affected by extreme values than the mean.
- Mode imputation was used for the categorical "Embarked" column.
- "Survived" and "Pclass" were converted to integer data types.
- Duplicate rows were removed to avoid repeated records.
- The original dataset was not modified; a separate cleaned CSV file was created.

Files
