# data-preparation
Data preparation and cleaning project

# Data Preparation

## Dataset
Titanic dataset used for data preparation and cleaning.

## Data Cleaning
- Handled missing values.
- Converted data types where required.
- Removed unnecessary columns.
- Checked for remaining missing values.

## Assumptions
- Missing numerical values were filled using the median.
- Missing categorical values were filled using the mode.
- Data types were converted to appropriate formats.

## Files
- `data_preparation.py` - Python script for data cleaning.
- `cleaned_titanic.csv` - Cleaned dataset.
